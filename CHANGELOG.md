# Changelog

Notable changes to WebPulse are recorded here.

## [0.1.0] - Initial Development Version

### Added
- Website registration and manual checks.
- HTTP and HTTPS monitoring.
- DNS validation and IP-pinned connections.
- Browser dashboard and Flask API.
- Automated monitoring using APScheduler.
- SQLite monitoring history.
- DOWN and RECOVERY alerts.
- Daily and weekly check-based uptime reports.
- Database indexes for monitoring history and reports.
- Pytest suite covering CLI, database, monitor, scheduler, and server.
- Developer and security documentation.

### Known Limitations
- No dashboard authentication.
- No multi-user authorization.
- No email or Telegram alert delivery.
- No production WSGI deployment configuration.
- MIT License adopted.
